# rmudos documentation

User and author documentation for the Rust LPC driver and its mudlibs.

| Doc | Audience | Contents |
| --- | --- | --- |
| [USAGE.md](USAGE.md) | Operators | Build, configure, run, connect, boot contract |
| [MUDLIB.md](MUDLIB.md) | World builders | Create LPC mudlibs, rooms, players, NPCs |
| [LPC.md](LPC.md) | LPC authors | Language subset supported by the compiler |
| [EFUNS.md](EFUNS.md) | LPC authors | Built-in function reference |
| [ARCHITECTURE.md](ARCHITECTURE.md) | Contributors | Driver internals and design notes |

Start with **USAGE** to run the sample world, then **MUDLIB** to build your own.
